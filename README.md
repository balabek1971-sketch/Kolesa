# QazAuto

Маркетплейс новых и подержанных автомобилей для Казахстана.

## Архитектура

- `src` — React/Vite интерфейс, развёртывается на Vercel.
- `backend` — Go API для защищённых операций, развёртывается на Railway.
- `supabase/schema-v2.sql` — PostgreSQL-схема, RLS, модерация, события и ранжирование.
- Supabase Auth — вход и регистрация только по номеру телефона.
- Cloudflare R2 — фотографии и одно видео до 60 секунд.
- Redis — кеш и ограничения запросов.

Секреты `service_role` и R2 разрешены только в Railway. В Vercel находятся
только публичные переменные `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`,
`VITE_API_BASE_URL` и `VITE_R2_PUBLIC_URL`.

## Локальный запуск интерфейса

```bash
npm install
npm run dev
```

Переменные берутся из корневого `.env.example`.

## Локальный запуск API

```bash
cd backend
go test ./...
go run ./cmd/api
```

Переменные API перечислены в `backend/.env.example`. Подробности находятся в
`backend/README.md`.

## Supabase

`schema-v2.sql` и `hotfix-20260722-media-rls.sql` применены 22 июля 2026 года.
Прежний `schema.sql` оставлен только как история MVP и повторно запускать его нельзя.

Для пошаговой публикации требуется один раз выполнить
`supabase/hotfix-20260724-listing-drafts.sql`. Он добавляет защищённое сохранение
черновиков и отправку собственного объявления на модерацию.

В Supabase Dashboard ещё требуется:

1. Подключить SMS-провайдера и включить Phone Auth.
2. Добавить локальный и production URL в список разрешённых URL.
3. Загрузить справочники марок, моделей и населённых пунктов отдельной миграцией.

Сессия Supabase сохраняется в браузере, автоматически обновляется и завершается
только после выхода пользователя либо отзыва сессии на сервере.
