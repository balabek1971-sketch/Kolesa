# QazAuto Market React

React MVP маркетплейса авто для Казахстана.

## Архитектура

- `src/App.jsx` - orchestration состояния приложения.
- `src/components` - UI-компоненты: поиск, каталог, форма продажи, аналитика.
- `src/components/controls` - переиспользуемые контролы поиска.
- `src/data` - демо-данные и справочники.
- `src/lib/search.js` - чистая логика фильтрации и сортировки.
- `src/lib/supabase.js` - клиент и будущие запросы к Supabase.
- `supabase/schema.sql` - структура базы и RLS-политики.

## Локальный запуск

```bash
npm install
npm run dev
```

## Vercel

1. Загрузить проект в GitHub.
2. Импортировать репозиторий в Vercel.
3. Framework preset: Vite.
4. Добавить переменные из `.env.example`.
5. Deploy.

## Supabase

1. Открыть Supabase SQL Editor и выполнить `supabase/schema.sql` целиком.
2. В Authentication → URL Configuration указать адрес сайта в `Site URL`.
3. Добавить локально и в Vercel переменные из `.env.example`.
4. После изменения переменных окружения повторно запустить Vercel Deploy.

Приложение использует Supabase для email-авторизации, чтения активных объявлений
и публикации объявлений авторизованными владельцами. Пока таблица пуста или API
недоступен, главная страница сохраняет демонстрационный каталог.

Никогда не добавляйте `service_role` key в Vite или Vercel-переменные с префиксом
`VITE_`: браузеру разрешён только публичный `anon`/publishable key.
